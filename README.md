# MyNotes

Локальное приложение для заметок под macOS на Swift (Apple Silicon и Intel): SwiftUI + AppKit, база SQLite.

## Сборка и запуск

Нужны macOS 14+ и Xcode (или Command Line Tools: `xcode-select --install`).

```bash
cd MyNotes
chmod +x build.sh
./build.sh
open build/MyNotes.app
```

По умолчанию собирается universal-бинарник (arm64 + x86_64): одно приложение работает и на Apple Silicon, и на Intel Mac. Можно собрать под одну архитектуру:

```bash
ARCHS=arm64 ./build.sh     # только Apple Silicon
ARCHS=x86_64 ./build.sh    # только Intel
```

Скрипт рисует иконку (набор PNG → `AppIcon.icns`), собирает `MyNotes.app`, подписывает его ad-hoc и выводит список архитектур.
Установка: `cp -R build/MyNotes.app /Applications/`.

Минимальная система — macOS 14 (Sonoma). Intel Mac, которые не обновляются до Sonoma, приложение не запустят.

Для разработки можно также открыть папку в Xcode (File → Open → `Package.swift`) или выполнить `swift run`.

## Синхронизация по локальной сети

**Как это работает**

1. На каждом устройстве MyNotes слушает TCP-порт (в «Настройки…» → «Синхронизация в локальной сети», по умолчанию **7443**).
2. На устройстве, которое хочет получить данные: «MyNotes → Синхронизироваться из локальной сети». Приложение сканирует подсети активных интерфейсов (только частные диапазоны, до /22), ищет открытый порт и проверяет, что на нём именно MyNotes.
3. Найденным устройствам отправляется запрос с именем вашего компьютера.
4. На другом устройстве появляется окно «Получен запрос на синхронизацию проектов от : <имя>» с вопросом «Разрешить синхронизацию?» (Да/Нет). По клавише Enter выбрано «Нет». При «Нет» ничего не передаётся.
5. При «Да» все проекты и заметки отправляются одним пакетом; в модальном окне видны проценты (и на отправляющем, и на принимающем устройстве).
6. Принимающее устройство проверяет контрольную сумму (SHA-256) и сливает изменения в свою базу.

Передача односторонняя: данные получает тот, кто запросил. Чтобы обменяться в обе стороны, повторите синхронизацию с другого устройства.

**Как принимаются изменения**

- У каждого проекта и каждой заметки есть идентификатор (UUID) и время последнего изменения. Для каждой записи побеждает более поздняя правка (last-writer-wins), поэтому важно, чтобы часы на устройствах были точными (автоматическая установка времени в macOS).
- Новые записи добавляются, изменённые обновляются (название, цвет, начертание, вложенность, текст заметок, перенос заметки между проектами).
- Слияние идемпотентно: повторная синхронизация тех же данных ничего не меняет и не создаёт дублей.
- Все изменения применяются одной транзакцией: либо все, либо ни одного.
- Защита от циклов во вложенности проектов (A внутри B и B внутри A).
- **Удаления не переносятся.** Слияние только добавляет и обновляет, чтобы ничего не потерять. Проект, удалённый на одном устройстве, останется на другом и при следующей синхронизации вернётся на первое.
- Одни и те же проекты, созданные на двух устройствах независимо (без синхронизации), имеют разные идентификаторы и после первой синхронизации окажутся рядом как два проекта.

**Безопасность**

- Ничего не передаётся без подтверждения «Да» на устройстве-источнике. Имя компьютера из запроса очищается от управляющих символов.
- Необязательный пароль синхронизации (хранится в связке ключей macOS): если задан на обоих устройствах, данные шифруются (ключ из пароля через PBKDF2, 200 000 итераций; каждый кусок шифруется AES-256-GCM с проверкой порядка). Без пароля данные идут по сети в открытом виде, поэтому используйте доверенную сеть или задайте пароль.
- Можно полностью отключить приём запросов переключателем в настройках.

**При первом запуске macOS спросит**

- «Принимать входящие подключения?» (брандмауэр) — нужно разрешить, иначе другие устройства не смогут подключиться.
- «MyNotes хочет найти устройства в локальной сети» — нужно разрешить, иначе сканирование ничего не найдёт. Если отказали: Системные настройки → Конфиденциальность и безопасность → Локальная сеть.

Если устройства не находятся: проверьте, что порт одинаковый на обоих, оба устройства в одной подсети (не в изолированной гостевой Wi-Fi), приложение запущено, а на источнике включён приём запросов.

## Импорт из OneNote

Приложение читает **родные файлы OneNote (`.one`)** напрямую, без экспорта, без входа в аккаунт и без сети.

1. В MyNotes: «Файл → Импорт → Из OneNote…» и выберите файлы `.one` **или папки** с ними (можно несколько сразу).
2. Каждый раздел (`.one`) становится проектом внутри проекта «OneNote», каждая страница — заметкой. Папки превращаются во вложенные проекты, так сохраняется структура «блокнот → раздел → страница».
3. Название страницы становится заголовком заметки, дата создания и последнего изменения берутся из файла.

Что переносится: текст (русский и другие языки), жирный/курсив/подчёркивание/зачёркивание, цвет текста и выделение, размеры, моноширинные шрифты, ссылки, отступы вложенных абзацев, маркированные и нумерованные списки, картинки (PNG, JPEG и другие форматы, понятные macOS), вложенные файлы, таблицы (как строки с разделителем «|»).

Что не переносится: рукописный ввод, аудио и видео, теги («важно», «задача»), положение блоков на странице (блоки идут сверху вниз), история версий страниц (берётся актуальная версия). Картинки в формате EMF/WMF пропускаются, об этом сообщается в итоговом окне. Пакеты `.onepkg` читать нельзя — выберите отдельные файлы `.one`.

Защита от зависаний: папки просматриваются в фоне с кнопкой «Отмена» и лимитами (глубина 8, до 20 000 записей, до 2 000 файлов, 20 секунд, файлы до 200 МБ). Ссылки, пакеты, скрытые и недоступные папки пропускаются, корень диска, домашняя папка, `/Users`, `/Library`, `/Applications` и другие системные каталоги не принимаются; при отказе в доступе программа сообщает, к чему доступа нет. Если файлов больше 200, перед импортом запрашивается подтверждение.

Файл `.one` не изменяется. Повторный импорт создаёт копии (проверка на дубликаты не выполняется).

Дополнительно поддерживаются файлы, экспортированные из OneNote или других программ: `.docx`, `.doc`, `.odt`, `.rtf`, `.rtfd`, `.html`, `.htm`, `.webarchive`, `.txt`, `.md`. Файлы `.mht`, `.pdf` пропускаются, и программа сообщит об этом.

## Передача на другие устройства Apple

Файл `.mynotes` по AirDrop уходит на любое устройство Apple, но открыть его сможет только Mac с MyNotes (версии для iPhone/iPad нет). На другом Mac скопируйте `MyNotes.app` и при первом запуске откройте через контекстное меню → «Открыть» (приложение подписано ad-hoc).
